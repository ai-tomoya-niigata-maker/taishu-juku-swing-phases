# 脊柱の傾きとスイングの面（3D動く図）

- `index.html` 単体で動く（three.js は cdnjs から読込）。`logo-text.png` を同じ場所に置く。
- URLパラメータ
  - `?preset=vert|tilt|side` … ①脊柱が垂直／②股関節屈曲→側屈／参考：側屈だけ
  - `?still=1&phi=110` … 静止画（phi=バット角 0〜300。バック0-75／アウト75-135／フロント135-200／フォロー200-300）
  - `?view=pitcher|side|top|iso` … 初期視点
- ローカル確認：`.claude/launch.json` の `spine-tilt`（scratchpad にコピーして配信）

## symptoms.html（図②③：症状A／B）
- `?fig=a|b` で単体表示、`?state=ok|bad`、`?still=1&phi=175`、`?view=...`
- モデル（index.html と同じ体・面。股関節屈曲30°・側屈8°固定）
  - 正しい形：スイングバックでグリップ高さ維持／フロントで前へ伸びる（半径+12cm）
  - A グリップダウン：スイングバック中にグリップ（と体の中心）が20cm下がる → 両ボールの下を通過（17cm下／12cm下）
  - B 意図的なアッパー：スイングフロント後半（150°〜）からバット全体が6cm持ち上がる＋前への伸びが減る（+12→+4cm） → 芯が上に移動し、ボールの高さには先しか残らない
- ボールの高さ切替（`?height=high|mid|low`）：高め105cm/屈曲24°、真ん中90cm/30°、低め75cm/36°。低めほど先に当たる（真ん中：芯13cm／先6cm、低め：先10cm／先4cm）
- ボール位置：前面 z=1.2、x=−0.10（引きつけた）／+0.35（前）
